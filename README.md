# Zhaolin Hu Portfolio

静态作品集，不需要安装依赖或构建。

## 工程结构

- `index.html`：页面结构与内容（首页、Ask、Work、About、Contact）。
- `styles.css`：布局、字体、主题色、响应式样式及动画。
- `app.js`：滚动转场、卡片吸附、鼠标互动、键盘、问答、导航与语言切换。
- `intro.js`：在页面绘制前决定是否播放开屏动画。
- `assets/images/`：首页背景与个人照片。
- `backups/`：历史版本；不参与当前页面运行。

## 本地预览

在这个目录运行：

```sh
python3 preview-server.py
```

浏览器访问 `http://127.0.0.1:8001/`。如已有预览服务器，无需重复启动。

开屏默认每个标签页会话播放一次。要重播，在地址后添加 `?intro=replay`。

## Hero 视频

- `hero-video.js` 单独控制 Hero 视频，不改变 `intro.js` 或既有开屏时序。
- `assets/hero-scroll.mp4` 来自上传的 `white-cloud-tap-pink-glow-1080p.mp4`，1920×1080、H.264、60fps 运动补帧、每 15 帧关键帧，无音轨，便于正反向滚动定位。
- Hero 可见且开屏完全退出后，静音行内播放到 2.5 秒（150/60 秒），手掌完整贴上玻璃，然后精确暂停。
- 沿用原有 80svh Hero 停留区间与 300svh 转场区间；转场进度 0–1 映射至 2.5 秒至最后一帧。反向滚动回到 2.5 秒，不重复播放开头。
- 保留原有文字、装饰、光晕、鼠标交互、呼吸动画和 Ask 布局；取消旧的背景缩放转场，改用视频自身动画。
- `assets/hero-hold.jpg` 是同一暂停帧，自动播放被阻止时定位到该帧；视频加载失败则保留静态图。减少动态效果时直接显示暂停帧，并沿用原有分段切换。
- 本地预览应使用 `preview-server.py`，它支持视频所需的 HTTP Range 请求。部署服务器也须支持字节范围请求；普通 Python 静态服务器可能导致视频加载或定位停在首帧。

Hero 在 2.5 秒定格后立即在食指上显示红点，随滚动转场淡出；位置按视频 cover 裁切计算以适配手机。

播放优化：从原 24fps 做运动补帧至 60fps；缓冲可播放后再启动，滚动定位按 60fps 对齐，定格直接停在已显示帧，不额外跳转。



当前定格逻辑：截图对应源视频 2.5 秒的画面；编码视频在 2.5–3.5 秒重复该静止画面，红点于 2.5 秒出现，播放器在 3 秒静止区间内暂停。滚动从 3.5 秒直接接回后续动作，反向回零显示 2.5 秒同一帧。

Hero 鼠标：固定尺寸十字准星与实时 X/Y 坐标，移除圆球、变形和拖尾。定格红点有独立的 64px 点击区域，可鼠标点击、触摸或键盘进入 Ask；同时保留原有滚动与反向回退。

Ask → Work 转场：深色颗粒从底部向上涌出，触顶后吸附在顶部并向两侧铺开，逐渐填满屏幕，边缘保留柔和颗粒带；Ask 随覆盖退场，导航在深色抵达顶部时切换浅色，反向滚动恢复。

颗粒密度：升起初期整个形状均由分散颗粒组成，触顶与铺开过程中逐渐增密，最后收拢成完整深色背景；不再只有边缘带颗粒。

触控板：Ask → Work 转场延长至 240vh；在 Work 边界前拦截越界惯性，同一次手势不会同时触发进场和切卡。切卡门槛为纵向 140px、横向 110px，惯性尾段全部结束后（260ms 空闲）才接受下一次手势。首尾卡片退出也需达到同样门槛。

Work 稳定性：卡片浏览期间将场景固定在视口顶部，再处理不可取消的惯性越界；精确到达边界时不重复纠正滚动。卡片 hover 只改边框和阴影，不再上浮或缩放。离开 Work 时恢复正常滚动定位。

Work → About：最后一张卡片后继续滚动，深色从实色散成颗粒并向上退出，About 在下方逐渐显露；转场长度 180vh。第四页使用视频云雾末帧 `assets/hero-ask.jpg` 与 Ask 相同的 22px 雾面模糊和浅灰透明层。交接前保持固定场景与占位高度，结束后恢复 About 自然滚动，反向滑动可回到 Work。
